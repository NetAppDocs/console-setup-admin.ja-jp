= NetApp Console のセキュリティ保護
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Console へのアクセスを制限し、Console エージェントを保護し、不正または意図しない変更がないかアクティビティを監視することで、ストレージ操作を保護します。

セキュリティは共同責任です。NetApp はコンソール サービスのセキュリティを確保しますが、適切な展開モードの選択、ユーザーおよびサービス アカウントへのアクセス制御、コンソール エージェントを展開する環境のセキュリティ確保、および組織内のアクティビティの監視はお客様の責任となります。



[[choose-the-appropriate-deployment-mode]]
== 適切な展開モードを選択してください

接続性、隔離性、および運用要件に基づいて、展開モードを選択してください。

* 標準モードでは、クラウド上でホストされているSaaSアプリケーションを使用します。
* 制限モードでは、NetApp API への外部接続が制限されたパブリッククラウド環境にコンソールをインストールします。
* プライベートモードでは、コンソールをオンプレミスまたは NetApp へのアウトバウンド接続のないエアギャップ環境にインストールします。


各モードには、利用可能な機能やセキュリティ要件が異なります。link:concept-modes.html["NetApp Consoleの導入モードについて学ぶ"]。



[[control-identity-and-access]]
== IDとアクセスの制御

IDおよびアクセス管理（IAM）を使用して、ユーザーとサービスアカウントに、タスクを実行するために必要なアクセス権限のみを付与します：

* リソースはプロジェクトごとに整理し、必要に応じて、ビジネスや業務の範囲を反映したフォルダを作成してください。
* 組織階層の最下位レベルにおいて、必要なアクセス権限を提供する事前定義された役割を割り当てます。
* 組織メンバー、サービスアカウント、およびそれぞれの役割を定期的に見直してください。不要になったアクセス権を削除してください。
* 組織の要件を満たす場合は、シングル サインオンにIDフェデレーションを使用します。フェデレーションはプライベートモードでは利用できません。
* ローカルユーザーには多要素認証（MFA）の使用を義務付け、サービスアカウントの認証情報をシークレットとして保護してください。サービスアカウントの認証情報が紛失した場合、またはローテーションが必要な場合は、サービスアカウントの認証情報を再作成してください。


link:concept-identity-and-access-management.html["NetApp Console の IAM について"]。



[[secure-console-agents]]
== セキュアコンソールエージェント

コンソール エージェントは、コンソールとストレージ システム、クラウドまたはオンプレミス環境との間を橋渡しします。エージェントはコンソールとの通信を開始します。コンソールはエージェントへの接続を開始しません。

各エージェントに以下の制御を適用します。

* 組織のホスト、ネットワーク、およびアクセス制御の要件を満たす環境にエージェントをデプロイしてください。
* 必要なアウトバウンド ネットワーク接続と必要なクラウド権限のみを許可します。展開前に、プロバイダー固有の権限とポート要件を確認してください。
* 送信トラフィックがプロキシ サーバを経由する必要がある場合は、サポートされているプロキシ構成を使用してください。
* ユーザーがHTTPS経由でエージェントのWebコンソールにアクセスする場合は、CA署名付き証明書をインストールしてください。
* エージェントソフトウェアを常に最新の状態に保ってください。プライベートモードのエージェントは手動でアップグレードする必要があります。
* AWS では、Console エージェントをホストする EC2 インスタンスに IMDSv2 を必須とすることを検討してください。


link:concept-agents.html["コンソールエージェントについて学ぶ"]。



[[reduce-unintended-changes]]
== 意図しない変更を減らす

組織管理者は、組織の読み取り専用モードを有効にすることができます。読み取り専用モードは、ユーザーが昇格した権限を要求するまで、ストレージ システムへの変更やデータ サービスの使用を防止するのに役立ちます。

link:task-enable-read-only-mode.html["読み取り専用モードを有効にする方法を説明します"]。



[[monitor-and-review-activity]]
== アクティビティの監視とレビュー

コンソールでストレージ管理とユーザーアクティビティを確認するには、操作タイムラインを使用してください。組織のセキュリティプロセスの一環として、メンバーのアクセス権限、役割の割り当て、サービスアカウントの認証情報、エージェントのステータス、および最近の操作状況を定期的に確認してください。

link:task-monitor-cm-operations.html["コンソール操作を監視する方法を説明します"]。
