= NetApp Consoleにログイン
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Consoleにサインアップすると、Web ベースのコンソールからログインして、データとストレージ インフラストラクチャの管理を開始できます。

サインアップ後、リソースにアクセスする前に、NetApp Console組織管理者がユーザー アカウントを組織に追加する必要があります。ログインしてもリソースが表示されない場合は、組織の管理者に問い合わせてください。link:task-user-settings.html#contact-admin["組織の管理者に問い合わせてください"]。

.手順
. NetApp Console の URL に移動します。URL は、組織が使用しているコンソールのモードによって異なります：
+
** *標準モード*: Webブラウザを開いて、 https://console.netapp.com["NetApp Console"^]にアクセスします。
** **制限モードまたはプライベート モード**：Web ブラウザーを開き、Console エージェントがインストールされている IP アドレスに移動します。


. *ログイン*ページで、ログインに関連付けられているメールアドレスを入力します。
. ログインに関連付けられた認証方法に応じて、資格情報を入力するように求められます。
+
** 既存のNetAppサポートサイト（NSS）の認証情報
** メールアドレスとパスワードを使用したNetApp Consoleアカウント
** 管理者が組織の ID フェデレーションを設定している場合は、フェデレーション接続
