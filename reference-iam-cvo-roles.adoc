= Cloud Volumes ONTAP の NetApp Console におけるアクセスロール
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
ユーザーに以下のロールを割り当てることで、コンソール内の Cloud Volumes ONTAP へのアクセス権を付与できます。Cloud Volumes ONTAP のロール機能を使用することで、組織内でユーザーが遂行する必要のあるタスクに特化したロールを柔軟に割り当てることができます。ロールの割り当て方法は、貴社のビジネス慣行およびストレージ管理方法によって異なります。

Cloud Volumes ONTAP は以下のロールを使用します：

* *Cloud Volumes ONTAP admin*：すべての Cloud Volumes ONTAP 操作へのフルアクセスを提供します。
* *Cloud Volumes ONTAP operator*：Cloud Volumes ONTAP システムの検出と管理（ボリューム、アグリゲート、スナップショット、レプリケーションの追加、一部の構成の変更、Cloud Volumes ONTAP バージョンのアップグレードなど）を含む重要なストレージ操作を実行します。
* *Cloud Volumes ONTAP ビューア*：Cloud Volumes ONTAP 情報への読み取り専用アクセスを提供します。このロールでは、アクティブな操作は実行できません。設定情報を含む一部のタブや画面は、ビューアには表示されない場合があります。


すべてのNetApp Consoleアクセスロールの詳細については、link:reference-iam-predefined-roles.html["アクセス ロール"]を参照してください。



[[how-role-changes-take-effect]]
== ロールの変更が反映される仕組み

Cloud Volumes ONTAP は、各ロール割り当てのローカルキャッシュを使用して、ロールベースアクセス制御（RBAC）を適用します。キャッシュは1時間ごとに自動的に更新されます。ロールが新たに割り当てられたり変更されたりした場合、変更が反映されるまでに最大1時間かかることがあります。更新が完了すると、コンソールはそのロールで許可されているワークフローを有効にします。


NOTE: Console エージェントが初めてデプロイされるとき、または既存の Console エージェントが Console 4.9.0 以降にアップグレードされるとき、Console は、組織内の既存ユーザーに Cloud Volumes ONTAP ロールを割り当てる1回限りのシード処理を実行します。この処理が完了するまでに最大30分かかる場合があります。
