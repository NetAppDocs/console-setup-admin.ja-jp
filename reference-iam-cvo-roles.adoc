= Cloud Volumes ONTAP の NetApp Console におけるアクセスロール
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
ユーザーに次のロールを割り当てて、NetApp Console内のCloud Volumes ONTAPへのアクセス権を付与できます。

* *Cloud Volumes ONTAP admin*：すべての Cloud Volumes ONTAP 操作へのフルアクセスを提供します。
* *Cloud Volumes ONTAP operator*：Cloud Volumes ONTAP システムの検出と管理（ボリューム、アグリゲート、スナップショット、レプリケーションの追加、一部の設定変更、Cloud Volumes ONTAP バージョンのアップグレードなど）を含む重要なストレージ操作を実行します。
* *Cloud Volumes ONTAP ビューア*：Cloud Volumes ONTAP 情報への読み取り専用アクセスを提供します。このロールでは、アクティブな操作は実行できません。設定情報を含む一部のタブや画面は、ビューアには表示されない場合があります。


link:reference-iam-predefined-roles.html["アクセスロールについて学ぶ"] 。

システムが含まれる組織、フォルダ、またはプロジェクトレベルで Cloud Volumes ONTAP ロールを割り当てます。プラットフォームロールを使用すると、ユーザーは NetApp Console リソースを管理でき、Cloud Volumes ONTAP ロールを使用すると、ユーザーは Cloud Volumes ONTAP システムを管理できます。ロール割り当ての計画に関するガイダンスについては、link:task-cvo-rbac-setup.html#plan-cloud-volumes-ontap-role-assignments["Cloud Volumes ONTAP のロールベースアクセスを設定する"] を参照してください。



[[role-migrations-for-existing-users]]
== 既存ユーザーのロール移行

Console エージェントをバージョン 4.9.0 以降にアップグレードすると、Console はプラットフォームロールに基づいて既存ユーザーに追加の Cloud Volumes ONTAP ロールを割り当てます。


NOTE: 既存の Console エージェントが Console 4.9.0 以降にアップグレードされると、Console は、組織内の既存ユーザーに Cloud Volumes ONTAP ロールを割り当てるワンタイムのシード処理を実行します。この処理には最大 30 分かかる場合があります。シード済みのロールを確認および調整するには、link:task-cvo-rbac-setup.html#review-roles-after-upgrading-the-console-agent["コンソールエージェントのアップグレード後にロールを確認する"]を参照してください。

以下のマッピングは、この一度限りの移行プロセスにのみ適用されます。

[cols="50,50"]
|===
| 既存のプラットフォームロール | Cloud Volumes ONTAPシード処理中に割り当てられるロール 


| スーパー管理者 | Cloud Volumes ONTAP管理者 


| 組織管理者 | Cloud Volumes ONTAP管理者 


| 連盟管理者 | Cloud Volumes ONTAP管理者 


| フォルダまたはプロジェクトの管理者 | Cloud Volumes ONTAP管理者 


| スーパービューアー | Cloud Volumes ONTAP ビューア 


| 組織閲覧者 | Cloud Volumes ONTAP ビューア 


| 連盟ビューア | Cloud Volumes ONTAP ビューア 


| フォルダーまたはプロジェクトビューア | Cloud Volumes ONTAP ビューア 


| その他のプラットフォームロール | Cloud Volumes ONTAP ビューア 
|===
コンソールは、既存のプラットフォームロールと同じ階層レベルで Cloud Volumes ONTAP ロールを割り当てます。これらのマッピングは、新規のロール割り当てには適用されません。シード済みのロールを確認および調整するには、link:task-cvo-rbac-setup.html#review-roles-after-upgrading-the-console-agent["コンソールエージェントのアップグレード後にロールを確認する"]を参照してください。


NOTE: 既知の問題により、現在、*Organization viewer* と *Cloud Volumes ONTAP viewer* のロールの組み合わせは組織スコープで機能しません。一時的な回避策として、*Organization admin* または *Folder or project admin* ロールを使用してください。



[[how-role-changes-take-effect]]
== ロールの変更が反映される仕組み

新規または更新されたロールの割り当てが有効になるまで、最大1時間お待ちください。Cloud Volumes ONTAP はロールの割り当てを1時間ごとに更新します。
