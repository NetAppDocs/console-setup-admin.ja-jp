= NetApp Console 組織を確認します
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Digital Advisorを使用している場合、会社がNetAppで複数のビジネスアカウントを持っているときは、コンソール組織を確認する必要があります。Digital Advisorには、コンソール組織に関連しない複数のNetAppアカウントが表示される場合があります。コンソール組織に関連付けられたリソースのみが表示されるようにするには、コンソール組織に関連付けるビジネスIDを確認できます。

コンソールでは、ユーザー アカウントごとに 1 つの NSS アカウントを関連付けることもサポートされています。link:task-manage-user-credentials.html["ユーザーレベルの資格情報を管理する方法を学ぶ"] 。



== 開始する前に

組織を検証するには組織管理者ロールが必要であり、ユーザーもNetApp Support Site（NSS）アカウントに関連付けられている必要があります。link:task-adding-nss-accounts["NSS アカウントを関連付ける方法を確認します"]。


NOTE: 会社にビジネス アカウントが 1 つしかなく、ユーザーが NetApp Support Site アカウントに関連付けられている場合、組織は自動的に認証されます。



== 組織を確認してください

.手順
. ユーザーが複数の組織にアクセスできる場合は、「組織」ドロップダウンメニューから検証する組織を選択してください。
. *管理 > IDとアクセス*で確認できます。
. *組織*を選択します。
