[IMPORTANT]
====
* 新しいエージェントの導入では、NetAppは次のエンドポイントを確認します：link:reference-networking-saas-console.html["ここに記載"^]。アップグレードに使用された以前のエンドポイントlink:reference-networking-saas-console-previous.html["ここに記載"]を使用している場合、この構成チェックはエラーで失敗します。NetAppは、できるだけ早くファイアウォールルールを更新して、現在のエンドポイントへのアクセスを許可し、以前のエンドポイントへのアクセスをブロックすることを推奨します。link:reference-networking-saas-console-previous.html#update-endpoint-list["ネットワークをアップデートする方法を学ぶ"]。
* ファイアウォールのエンドポイントを更新しても、既存のエージェントは引き続き動作します。
