2+| *商用地域または主権地域* 商用地域または主権地域にConsoleエージェントをインストールする場合、インストーラーはこれらのエンドポイントにアクセスする必要があります： 
|===
オプション1に記載されているエンドポイントは、より安全であるため推奨されます。オプション1に記載されているエンドポイントは許可し、オプション2に記載されているエンドポイントは許可しないようにファイアウォールを設定することをお勧めします。これらのエンドポイントについて、次の点に注意してください：** オプション1に記載されているエンドポイントは、Consoleエージェントの3.9.47リリース以降でサポートされています。Consoleエージェントの以前のリリースとの下位互換性はありません。** Consoleエージェントは、まずオプション2に記載されているエンドポイントに接続します。これらのエンドポイントにアクセスできない場合、Consoleエージェントはオプション1に記載されているエンドポイントに自動的に接続します。** ConsoleエージェントをNetApp Backup and RecoveryまたはNetApp Ransomware Resilienceで使用する場合、オプション1のエンドポイントはサポートされません。この場合、オプション1に記載されているエンドポイントを禁止し、オプション2に記載されているエンドポイントを許可することができます。

ホストはインストール中にオペレーティング システム パッケージの更新を試みる場合があります。ホストは、これらの OS パッケージのさまざまなミラーリング サイトに接続できます。
