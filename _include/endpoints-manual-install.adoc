* コンソール エージェントをNetApp Backup and RecoveryまたはNetApp Ransomware Resilienceと共に使用する場合、オプション 1 のエンドポイントはサポートされません。この場合、オプション 1 にリストされているエンドポイントを禁止し、オプション 2 にリストされているエンドポイントを許可することができます。
