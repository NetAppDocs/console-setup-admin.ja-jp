== 失敗したConsoleエージェント展開のトラブルシューティング

デプロイメントレポートを使用してConsoleエージェントのデプロイをブロックした原因を確認し、再試行してください。

Consoleは、「エージェント構成の検証」チェックボックスが選択されている場合にのみレポートを提供します。デプロイが成功した場合、レポートは生成されません。

.手順
. *エージェントの展開に失敗しました*ダイアログボックスで、*レポートをダウンロード*を選択します。
+
Consoleは、検証レポートを含むPDFファイルをダウンロードします。

. レポートを確認し、記載されている問題を修正してください。
. ダイアログボックスで「最初からやり直す」を選択し、再度デプロイを完了してください。
+
もう一度試すには、最初からすべての手順をやり直す必要があります。
