= NetApp Consoleについて学ぶ
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Consoleは、すべてのクラウドおよびオンプレミスシステム全体でデータを管理および保護するのに役立ちます。データの安全性を保ち、正常に動作させるためのツールが含まれています。

コンソールをSaaS（Software-as-a-Service）アプリケーションとして使用するか、クラウドまたはオンプレミス環境（制限モードまたはプライベートモード）にインストールします。各モードは、異なる機能セットとセキュリティ要件をサポートします。

コンソールは、環境に導入したコンソールエージェントと連携して、リソースを管理し、オンプレミス環境とクラウド環境全体のプロセスをオーケストレーションします。



[[choose-how-to-access-netapp-console]]
== NetApp Console へのアクセス方法を選択

NetApp Console の使用を開始するには、SaaS アプリケーションにサインアップするか（標準モード）、クラウドにインストールするか（制限モード）、オンプレミスにインストールします（プライベート モード）。一部の機能は、制限モードまたはプライベート モードでは使用できません。

link:concept-modes.html["展開モードの詳細"] 。



[[extend-console-capabilities-with-console-agents]]
== Console エージェントで Console 機能を拡張する

コンソールエージェントは、NetApp Console SaaSアプリケーションとクラウドベースのAPIへの接続を提供する軽量なソフトウェアコンポーネントであり、高度な機能とデータサービスを実現します。

制限モードまたはプライベートモードでは、クラウドまたはオンプレミス環境にコンソール エージェントをインストールして、NetApp コンソール アプリケーションにアクセスします。NetApp コンソールとその API への直接接続を必要とする機能をサポートするには、追加のエージェントを導入する必要があります。

link:concept-agents.html["コンソールエージェントの詳細"] 。



[[manage-user-access-and-permissions-in-netapp-console]]
== NetApp Console でユーザーのアクセスと権限を管理する

コンソールは、アイデンティティとアクセス管理（IAM）を提供し、データ インフラストラクチャ全体のセキュリティと制御を向上させます。組織の役割と責任に基づいてストレージとデータ サービスを編成し、運用効率を維持しながら不正アクセスのリスクを軽減します：

* 最上位の_organization_では、インフラストラクチャ全体にわたってストレージ システムとプロジェクトへのアクセスを許可したり取り消したりできます。
* _フォルダ_を使用すると、ビジネス機能やコンプライアンス要件に基づいてストレージリソースとプロジェクトをグループ化できます
* _Projects_ を使用すると、特定のストレージ システム、ボリューム、データ サービスにアクセスできるチームを制御できます
* _ロールベースのアクセス制御（RBAC）_を使用すると、さまざまなレベルのチームメンバーにストレージ管理権限を付与できるため、過度のアクセス権を与えることなくタスクを委任できます


link:concept-identity-and-access-management.html["NetApp ConsoleのIAMの詳細"]



[[security-and-compliance-in-netapp-console]]
== NetApp Console のセキュリティとコンプライアンス

シングル サインオン（SSO）などのセキュリティとコンプライアンス機能を有効にして、ストレージおよびデータ サービスへのアクセスを制御します。組織管理者ロールを持つユーザーは、デフォルトで読み取り専用モードを設定できます。これにより、ユーザーはストレージ システムに変更を加えたりデータ サービスを使用したりするために、昇格された権限を要求する必要があります。NetApp Consoleを使用して、ストレージ管理とユーザー アクティビティを監視することもできます。NetApp ConsoleはSOC 2 Type 2認証を取得しており、NetAppは顧客にSOC 2レポートを提供します。

https://www.netapp.com/company/trust-center/compliance/soc-2/["NetAppのSOC 2レポートを見る"^]



[[netapp-console-capabilities-and-supported-storage]]
== NetApp Consoleの機能とサポートされるストレージ

NetApp Consoleは、オンプレミス環境とクラウド環境全体で、幅広いストレージタイプ、機能、データサービスをサポートします。Consoleを使用して、ストレージシステムを管理し、その健全性とパフォーマンスを監視し、データサービスを有効にしてデータを保護および最適化します。

[[storage-management-and-health-services-in-netapp-console]]
=== NetApp Console のストレージ管理とヘルスサービス

NetApp Consoleは、単一のインターフェースを介してNetAppストレージ インフラストラクチャの統合管理を提供します。

コンソールでは、_システム_ は検出または展開されたストレージを表します。コンソールで直接ストレージボリュームを管理するか、システムの管理インターフェイスを開いてその他のオプションを確認してください。

image:screenshot-canvas.png["複数のシステムを表示するコンソールのスクリーンショット。1 つが選択され、 NetAppデータ サービスを有効にするか、*Enter system* を選択してストレージを管理する機能が表示されます。"]

ストレージ管理に加えて、インフラストラクチャ サービスを使用して、すべての環境にわたってストレージ インフラストラクチャを監視および管理します。

ヘルスとパフォーマンスの監視:: ストレージ システムの健全性とパフォーマンスのダッシュボードを表示し、問題が発生する前に修正するためのアラートを受け取ります。
Licenses and subscriptions:: ライセンスとサブスクリプションを管理および監視します。
ライフサイクルプランニング:: スペースが不足しているクラスタを特定し、必要に応じて容量を追加するかデータを移動します。
NetAppデジタルアドバイザー (Active IQ):: 予測分析とプロアクティブなサポートを使用して、データ インフラストラクチャを最適化します。
ソフトウェアアップデート:: ONTAP アップグレードの評価、計画、完了を自動化します。
ストレージアラート:: ONTAP環境の容量、可用性、パフォーマンス、保護、セキュリティに関連する問題を表示します。
システムページ:: すべてのストレージ システムを 1 か所で表示し、管理インターフェイスにすばやくアクセスできます。ドラッグ アンド ドロップで、システム ページから直接データ サービスを有効にします。
サステナビリティダッシュボード:: ストレージ システムの持続可能性を分析します。




[[data-security-and-protection-services-in-netapp-console]]
=== NetApp コンソールのデータセキュリティと保護サービス

組み込みのデータサービスを使用して、重要なデータを保護し、ストレージ効率を最適化します。

NetApp Backup and Recovery:: クラウドおよびオンプレミスのデータをバックアップおよびリストアします。サブスクリプションが必要です。
NetApp Copy and Sync:: オンプレミスとクラウド データ ストア間でデータを同期します。
NetApp Disaster Recovery:: VMware Cloud on Amazon FSx for ONTAP を災害復旧サイトとして使用して、オンプレミスの VMware ワークロードを保護します。サブスクリプションが必要です。
NetApp Ransomware Resilience:: ランサムウェア攻撃につながる可能性のある異常を検出します。ワークロードを保護および回復します。サブスクリプションが必要です。
NetApp Replication:: バックアップと災害復旧をサポートするために、ストレージ システム間でデータを複製します。
