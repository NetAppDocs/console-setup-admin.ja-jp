[[console-agent-4-13-0]]
=== Console エージェント 4.13.0

4.13.0 リリースでは、標準モードと制限モードの両方がサポートされています。

Consoleエージェントのこのリリースには、セキュリティの改善とバグ修正に加え、以下の新機能が含まれています。ISOを使用してvCenterにデプロイされたConsoleエージェントを4.13.0にアップグレードする場合は、アップグレードの完了後にVMが再起動されることを確認してください。VMは自動的に再起動する場合があります。



==== Consoleエージェントをデプロイする際に、AWSデプロイロールを自動的に作成します

開始する前に、AWSにConsoleエージェントをデプロイするためのIAMロールを作成する必要はなくなりました。NetApp Consoleがロールを作成できます。link:https://docs.netapp.com/us-en/console-setup-admin/task-install-agent-aws-console.html["ConsoleからAWSにConsoleエージェントを展開する方法について説明します"^]



[[netapp-console-administration]]
=== NetApp Console管理

今回のリリースには、セキュリティの改善とバグ修正に加え、以下の新機能が含まれています。



==== Cloud Volumes ONTAP貢献者ロールを割り当てます

Cloud Volumes ONTAP Contributorロールを割り当てることで、メンバーにCloud Volumes ONTAPシステムを管理するための幅広いアクセス権を付与しつつ、システム、ボリューム、アグリゲート、またはレプリケーション関係の削除は許可しないようにすることができるようになりました。link:https://docs.netapp.com/us-en/console-setup-admin/reference-iam-cvo-roles.html["Cloud Volumes ONTAP のロールベースアクセスの詳細については、こちらをご覧ください"^]。
